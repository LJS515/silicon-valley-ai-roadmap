# Silicon Valley AI Developer Roadmap

This repository records my long-term roadmap to become an AI Developer with strong engineering fundamentals, open-sourcce experience, and international technical communication ability.

## Core Principle

I use AI to write code faster and solve problems more boldly, not because I cannot code without AI.

AI can help me write code, but I must understand, verify, debug, refactor, and improve it.

I do not want to be a passive user of AI tools, I want to stand above the tools and become a stronger builder.

## Day 1 Goal

The goal of Day 1 is to build the basic developer workflow:

```
Define a goal - Write code - Run code - Verify output - Commit changes - Push to GitHub - Reflect
```
