# AI Coding Principles

## 1. AI is a power tool, not a crutch

I use AI to move faster, explore more solutions, and reduce repetitive work.

I do not use AI as a replcement for understanding.

## 2. I must understand the code

After AI generates code, I must be able to expalin:

- What the code does
- Why this structure is used
- What could go wrong
- How to test it
- How to debug it
- How to improve it

## 3. I must verify the result

AI-generated code is note correct bt default.

I must run it, test it, inspect it, and fix it.

## 4. I must build fundamentals

The long-term goal is not to become a prompt operator.

The long-term goal is to become a strong AI Developer who can build real systems.

## 5. I must document my work

Every serious project should include:

- README
- Setup guide
- Usage example
- Architecture notes
- Tests
- Reflection
- Roadmap

## 6. I must practice English technical communication

English is part of the engineering workflow.

I will gradually practice:

- README writing
- Commit messages
- Issue comments
- Pull request descriptions
- Technical blog posts
- Demo scripts
- Interview answers
